主密码保险库

SSH 密码 / API Key 等敏感信息以主密码加密保存在本地，并随 Git 同步一起分发。

确认主密码

主密码遗失后无法恢复，只能重置保险库并重新输入所有密码。

主密码不一致

Git 同步仓库中的保险库由另一套主密码加密，与本机不一致。为避免丢失数据，做出选择前不会覆盖任何一侧。
